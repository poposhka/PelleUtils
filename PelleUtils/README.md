# PelleUtils

PelleUtils is a lightweight utility addon template for World of Warcraft Forever.

## Files

- `PelleUtils.toc` — addon manifest
- `Core.lua` — core logic, saved vars, slash commands
- `Config.lua` — basic UI panel

## Install

1. Copy the `PelleUtils` folder into your World of Warcraft Forever `AddOns` directory.
2. Reload the UI with `/reload`.
3. Use commands such as:
   - `/pu toggle`
   - `/pu status`
   - `/pu say`
   - `/pu help`
   - `/puconfig`

## Customize

Edit the `addon.Defaults` table and the command behavior in `Core.lua` to tailor the addon for your own utility needs.
